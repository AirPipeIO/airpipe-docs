# Install

  - Register an account at https://app.airpipe.io/register.
  - Check your email to verify your account and log in.
  - You may use the hosted mode in the website interface itself or setup one of the self hosted modes as below.

## Hosted (Managed)
No further setup required once you have registered and verified your account. Easy!

## Self Hosted (Unmanaged)

- Generate an API Key at https://app.airpipe.io/apikeys.
- We recommend using Linux as your primary production deployment, unless you have specific OS requirements.

## Upgrading

A self-hosted engine does not update itself. The app lists each one that reports with your
API keys, and the version it runs, at [Self-hosted agents](https://app.airpipe.io/agents),
and flags any older than the current release
([latest.version](https://download.airpipe.io/latest.version)). Replicas that share one
identity are listed as its processes, so a replica left on an old version shows too.

- **Linux, installed with `setup.sh`:** install the latest binary in place, then restart
  the service. (`--update` replaces the binary only; your configs and service are kept.)

  ```bash
  curl -s https://download.airpipe.io/setup.sh | sudo bash -s -- --update
  sudo systemctl restart airpipe
  ```

- **Mac, installed with `setup.sh`:** the same, then restart the service.

  ```bash
  curl -s https://download.airpipe.io/setup.sh | sudo bash -s -- --update
  sudo launchctl kickstart -k system/com.airpipe
  ```

- **Docker:** pull the new tag (`airpipeio/agent:latest`, or a version such as
  `airpipeio/agent:3.21.0`) and recreate the container.
- **Kubernetes:** set the image tag in the deployment; the rollout replaces the pods one at
  a time.
- **Any other install:** download the binary for your platform from
  `https://download.airpipe.io/<version>/<os>/<arch>/airpipe` and replace the old one.
